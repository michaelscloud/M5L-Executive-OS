# Open Actions — Live Register

**This is the single source of truth for what is currently open.** Every open action lives here regardless of which week it was raised in, so nothing is stranded when a week's file is archived.

- Actions keep the `WNN#N` id they were given when raised. Ids never change.
- Weekly files (`actions/actions-YYYY-Www.md`) remain the record of what was **opened and closed** in that week. They are not the live list.
- When an action is closed, mark it `[x]` in its week file **and remove it from here**, then sync `/people` and `/projects` as usual.
- When a new action is raised, add it to the current week's file **and here**.

See "Two files, two jobs" in `CLAUDE.md` for the full behaviour.
