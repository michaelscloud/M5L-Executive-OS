# Tidy — Remove Excess Whitespace

Review the file(s) specified (or the most recently edited file if none given) and remove excess blank lines:

- No more than one blank line between sections
- No trailing blank lines at the end of the file
- No blank lines immediately after a heading
- No blank lines immediately before a closing section

Make the edits silently using targeted Edit calls — do not rewrite whole files. Confirm what was tidied when done.
